СВІТ ПРИРОДИ — НАВЧАЛЬНИЙ САЙТ

СТРУКТУРА:
- index.html       головна сторінка
- gallery.html     фотогалерея з фільтрами та переглядом фото
- phenomena.html   природні явища, CSS-анімації та вікторина
- style.css        оформлення всіх сторінок
- script.js        інтерактивні функції

ЯК ВІДКРИТИ:
1. Розпакуйте архів у будь-яку теку.
2. Відкрийте файл index.html у браузері.
3. Перейдіть між сторінками через меню у верхній частині сайта.

ВАЖЛИВО:
Для фотографій та шрифтів потрібне підключення до Інтернету.
Анімації, меню, перемикач теми, фільтри галереї та вікторина працюють локально.
Це статичний сайт на HTML, CSS і JavaScript — його можна розмістити на GitHub Pages.
